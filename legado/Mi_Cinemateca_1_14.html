Los títulos, pósteres y rutas se guardan en el navegador de esta computadora. No se copian videos ni se modifica ninguna carpeta. Para abrir un video de una sesión anterior, el navegador puede pedir autorización para acceder al disco. Mantené este archivo en la misma ubicación y abrilo siempre con el mismo navegador y perfil. Este producto utiliza la API de TMDb, pero no está avalado ni certificado por TMDb. Metadatos: The Movie Database. La clave se conserva solo durante la sesión. Si falta el ID IMDb, se envían a TMDb el título y el año para buscar una coincidencia. Las fichas dudosas quedan pendientes.
